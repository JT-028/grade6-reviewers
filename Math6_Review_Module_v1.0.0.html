Step-by-Step Solver 🧮 ⏱ ~12 min

Four walkthroughs for the mix-ups: real-world signs, mixed-sign subtraction (the 9-A hole), multiply/divide signs, and scientific notation.

➕ Solver A - Integers in the Real World

Up, above, deposit, profit, east, north = positive. Down, below, withdrawal, debt, west, south = negative. Zero is neither.

➖ Solver B - Add / Subtract Integers

Like signs: add the sizes, keep the sign. Unlike signs: subtract the sizes, keep the sign of the bigger size. Subtraction means add the opposite. This is Practice Set 9-A.

✖️ Solver C - Multiply / Divide Integers

Same signs → positive product or quotient. Different signs → negative. This is the 12-B "answer at home" skill.

🔬 Solver D - Powers & Scientific Notation

an means a multiplied by itself n times, not added. a0 = 1 (a ≠ 0). a−n = 1/an. Scientific notation is a number 1 ≤ N < 10 times a power of 10.
